# المحوّل الذكي PDF — إصدار تجريبي 1.1

## الميزات المضافة في الكود
- واجهة عربية RTL.
- التقاط صورة بالكاميرا وإضافة صور متعددة.
- إنشاء PDF متعدد الصفحات من الصور.
- فتح PDF ورسم صفحاته محلياً باستخدام Android PdfRenderer.
- OCR بواسطة Tesseract4Android مع نماذج ara + eng + fra تُنزّل عند أول استخدام.
- تصدير النص المستخرج إلى DOCX مع خصائص RTL، أو TXT.
- تصدير XLSX كخلايا نصية؛ تقسيم الأعمدة تقريبي ويعتمد على المسافات/علامات الفصل في OCR.

## قيود مهمة
- التقاط الكاميرا الحالي يستقبل صورة المعاينة المصغرة من تطبيق الكاميرا، وليس صورة أصلية عالية الدقة.
- لا يوجد قص تلقائي للوثائق أو تصحيح منظور.
- OCR والجداول ليست مضمونة 100%؛ جودة الصورة وتخطيط المستند يؤثران.
- XLSX لا يستعيد بنية الجدول الأصلية بدقة؛ يضع النص في خلايا وفق تقسيم تقريبي.
- هذه نسخة تجريبية تحتاج بناء واختباراً على جهاز فعلي. لم يتم إنشاء APK أو توقيعه هنا.

## البناء من الهاتف
1. أنشئ مستودعاً جديداً في GitHub وارفع ملفات المشروع.
2. من تبويب Actions شغّل workflow: Build Android APK.
3. نزّل artifact باسم SmartPDFArabic-debug-apk.
4. فك الضغط وثبّت app-debug.apk. هذا APK تجريبي debug وليس إصداراً نهائياً موقعاً للنشر.

## المتطلبات
- اتصال إنترنت أول مرة لتنزيل ملفات اللغات العربية والإنجليزية والفرنسية.
- مساحة تخزين كافية للنماذج والملفات.
