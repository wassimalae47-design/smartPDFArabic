# المحوّل الذكي PDF — مشروع أندرويد أولي

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية واتجاه من اليمين إلى اليسار.
- التقاط صورة بالكاميرا عبر تطبيق الكاميرا الموجود في الهاتف.
- اختيار عدة صور من الهاتف.
- إنشاء ملف PDF متعدد الصفحات وحفظه داخل مجلد التطبيق.

## ما الذي لم يكتمل؟
- OCR عربي/فرنسي/إنجليزي.
- تحويل PDF إلى DOCX وXLSX فعلياً.
- تحسين قص الحواف وتصحيح المنظور.
- مزامنة/معالجة سحابية اختيارية.

لا تعتبر هذه النسخة تطبيق التحويل النهائي؛ أزرار Word وExcel حالياً لا تنفذ التحويل.

## بناء APK دون كمبيوتر
1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد.
2. افتح تبويب Actions.
3. اختر workflow باسم Build Android APK ثم Run workflow.
4. بعد نجاح البناء افتح نتيجة التشغيل (Artifacts) ونزّل:
   `SmartPDFArabic-debug-apk`
5. فك ضغط الملف وثبّت `app-debug.apk` على هاتف Android. قد تحتاج للسماح بالتثبيت من هذا المصدر.

## فتح المشروع في Android Studio
افتح مجلد المشروع ثم نفّذ Gradle Sync وبعدها Build > Build APK(s).

## ملاحظة تقنية
هذا مشروع بداية قابل للتطوير، وليس APK موقعاً للإصدار النهائي. قبل النشر ينبغي إضافة محرك OCR عربي فعلي واختبارات للتحويل، ثم إنشاء توقيع إصدار خاص.
